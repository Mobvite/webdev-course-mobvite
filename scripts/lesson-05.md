# Lección 05 — Crear una página web sencilla

**Duración estimada:** 15 minutos  
**Tema:** Página de perfil personal con HTML y CSS  
**Herramienta de práctica:** CodePen  
**Conocimientos previos:** HTML y CSS básicos.

## Objetivos de aprendizaje

Al finalizar esta lección, el estudiante podrá:

- Crear el contenido de una página de perfil con HTML.
- Aplicar colores, espacios y bordes mediante CSS.
- Relacionar las clases del HTML con los selectores del CSS.
- Revisar el resultado y corregir errores en la vista previa.

## Introducción

Para comenzar, ingresaremos a la página web de CodePen e iniciaremos sesión si es necesario. Luego haremos clic en “New Pen” para crear un proyecto. El editor nos mostrará los archivos HTML, CSS y JavaScript, además de una vista previa. En este ejercicio utilizaremos HTML y CSS: primero completaremos todo el contenido de nuestra página de perfil y después le daremos estilo. Mantendremos visible la vista previa para observar cómo cambia la página. No necesitamos instalar ningún programa ni buscar imágenes, porque utilizaremos un emoji como avatar.

## HTML

CodePen ya nos proporciona una estructura HTML inicial, así que no tenemos que borrarla ni escribirla nuevamente. Al comienzo vemos una declaración que indica al navegador el tipo de documento. Después aparece la etiqueta que contiene toda la página; allí cambiaremos el idioma de inglés a español, sustituyendo “en” por “es”. Dentro de la sección llamada “head” encontramos información que ayuda a presentar la página. Dejaremos la línea de codificación, que permite mostrar correctamente las tildes, la letra eñe y los emojis. También conservaremos la línea de “viewport”, que ayuda a que el contenido se adapte a distintos tamaños de pantalla. Otra línea conecta el HTML con el archivo “style.css”; es importante mantenerla, porque gracias a ella se aplicarán los colores y demás estilos que escribiremos más adelante. El título predeterminado dice “Pen”, así que lo cambiaremos por “Mi primera web”. Ese título identifica nuestro trabajo en la pestaña del navegador. Una vez hechos estos cambios, pasaremos a la sección “body”, donde se escribe el contenido que realmente verá quien visite la página. Colocaremos nuestro trabajo antes de la línea que menciona “script.js”. Ese archivo viene incluido en la plantilla, pero no necesitaremos usar JavaScript en este proyecto. Antes de añadir contenido, conviene distinguir las dos partes que acabamos de revisar: “head” guarda información sobre el documento, mientras que “body” contiene nuestra página visible. Esta diferencia nos ayudará a saber dónde escribir cada elemento sin modificar por accidente las líneas que CodePen ya preparó.

Dentro de “body” abriremos un bloque principal con la etiqueta “main” y le daremos la clase “tarjeta”. La clase es un nombre que elegimos para identificar ese bloque cuando trabajemos en CSS. Primero añadiremos un emoji de una persona frente a una computadora y le asignaremos la clase “avatar”. Será el elemento visual que aparece en la parte superior del perfil. Debajo escribiremos “Aprendiendo desarrollo web” en un elemento con la clase “etiqueta”; esta frase comunica rápidamente el tema de la página. A continuación pondremos el nombre “¡Hola, soy Alex!” dentro del título principal, y después añadiremos un párrafo que diga que estamos creando nuestra primera página con HTML y CSS. Alex es solo un ejemplo y podrás reemplazarlo por tu nombre. Seguiremos con un bloque llamado “habilidades”. En su interior escribiremos dos elementos, uno para HTML y otro para CSS, acompañados por emojis. Al final colocaremos un bloque con la clase “proyecto” y el mensaje “¡Esta es mi primera página web!”. Después cerraremos todas las etiquetas en el orden correcto. Es útil pensar en ellas como cajas: las habilidades están dentro de la tarjeta y la tarjeta está dentro del cuerpo de la página. Si abrimos una caja, tenemos que cerrarla. Antes de pasar al CSS, miraremos la vista previa para comprobar que aparecen el avatar, la frase superior, el nombre, la descripción, las habilidades y el mensaje final. Aunque todavía se vea simple, ya habremos construido el contenido completo. Si algo falta, revisaremos el texto y las etiquetas antes de continuar. Así podremos saber que cualquier cambio posterior en la apariencia viene del CSS y no de haber agregado información nueva.

## CSS

Ahora abriremos el archivo “style.css”. Aquí escribiremos reglas para cambiar cómo se ve el contenido que ya colocamos en HTML. Comenzaremos con una regla para “body”, que corresponde al cuerpo de toda la página. Primero quitaremos el margen predeterminado para que el fondo llegue hasta los bordes de la ventana. Luego indicaremos una altura mínima equivalente a toda la pantalla; esto nos dará espacio para colocar la tarjeta en el centro. Utilizaremos una cuadrícula y una propiedad de centrado para situar allí el contenido. Mientras escribimos, observaremos cómo la tarjeta cambia de posición en la vista previa. Después elegiremos Arial como fuente, porque es sencilla y fácil de leer. La última propiedad de esta primera regla creará un fondo degradado entre violeta y turquesa. Un degradado hace que un color se transforme gradualmente en otro. Podemos detenernos aquí para mostrar el antes y el después, e incluso probar otro color durante unos segundos antes de volver al original. A continuación seleccionaremos la clase “tarjeta”. En CSS, escribimos un punto antes del nombre cuando queremos seleccionar una clase. Le daremos un ancho máximo para que el perfil no se extienda por toda la pantalla, un margen para dejar espacio por fuera y un espacio interior para separar el texto de sus bordes. También centraremos su contenido, pondremos el fondo blanco y redondearemos las esquinas. El contraste entre la tarjeta blanca y el fondo degradado hará que el perfil destaque. Este es un buen momento para explicar la diferencia entre margen y espacio interior: el margen separa la tarjeta de su entorno; el espacio interior deja aire entre el contenido y el borde de la propia tarjeta.

Después ajustaremos los detalles de la tarjeta. Seleccionaremos la clase “avatar” y aumentaremos el tamaño del emoji para que funcione como una imagen de presentación. Aplicaremos el mismo color violeta a la frase superior y al título principal; como ambos compartirán una propiedad, podremos escribir sus selectores en una sola regla separados por una coma. Si la frase no cambia de color, revisaremos que la clase “etiqueta” tenga exactamente el mismo nombre en HTML y CSS. Luego trabajaremos con las habilidades. Seleccionaremos los elementos que están dentro del bloque “habilidades”, les daremos espacio alrededor y en su interior, un fondo violeta claro y bordes redondeados. De esta manera, “HTML” y “CSS” se verán como pequeñas etiquetas colocadas una junto a la otra. Finalmente seleccionaremos la clase “proyecto” para destacar el mensaje de cierre: dejaremos espacio por encima, añadiremos espacio interior, pondremos las letras blancas sobre un fondo violeta y redondearemos sus esquinas. Al terminar, revisaremos la vista previa completa. Debemos ver el fondo degradado, la tarjeta blanca centrada, el avatar grande, los textos con color, las habilidades resaltadas y el mensaje final. Si un estilo no aparece, comprobaremos que el archivo se llame “style.css”, que las clases coincidan con las del HTML y que las reglas estén bien cerradas. Por último, podemos cambiar el nombre, la descripción o los colores para hacer una versión personal. Con este ejercicio comprobamos que HTML organiza el contenido y CSS define su apariencia. Guardaremos el Pen para conservar nuestra primera página web.
