# Lección 06 — Consejos y Próximos Pasos

**Duración estimada:** 10 minutos  
**Tema:** Errores comunes, buenas prácticas y próximos pasos  
**Formato:** Presentación de diapositivas  
**Conocimientos previos:** HTML y CSS básicos.

# Objetivos de aprendizaje

Al finalizar esta lección, el estudiante podrá:

- Reconocer errores comunes en HTML y CSS.
- Aplicar buenas prácticas básicas al escribir código.
- Seguir pasos sencillos para encontrar errores.
- Comprender que no es necesario memorizar todos los elementos de HTML y CSS.
- Identificar recursos y formas de continuar aprendiendo desarrollo web.

# 0:00 – 0:50 | Diapositiva 1 — Consejos y próximos pasos

Durante este curso aprendimos los fundamentos necesarios para comenzar a crear nuestras propias páginas web.

Aprendimos a utilizar HTML para construir la estructura y agregar contenido.

Después utilizamos CSS para cambiar la apariencia de nuestra página mediante colores, fuentes, bordes y espacios.

Antes de finalizar el curso, vamos a revisar tres temas importantes.

Primero veremos algunos errores comunes que podemos cometer cuando estamos comenzando.

Después conoceremos algunas buenas prácticas para mantener nuestro código organizado.

Y finalmente veremos cómo podemos continuar aprendiendo y practicando después de este curso.

# 0:50 – 1:40 | Diapositiva 2 — Lo que aprendimos hasta ahora

Hagamos primero un pequeño repaso.

HTML nos permite definir la estructura de una página.

Con HTML podemos agregar títulos, párrafos, listas, imágenes y enlaces.

CSS, en cambio, nos permite controlar cómo se ve nuestra página.

Podemos cambiar colores, fuentes, bordes, espacios y alineaciones.

Podemos resumirlo de una forma muy sencilla:

HTML nos dice qué contiene nuestra página.

CSS nos dice cómo queremos que se vea.

Ahora que conocemos ambas herramientas, veamos algunos errores que podemos encontrar mientras programamos.

# 1:40 – 2:55 | Diapositiva 3 — Error común 1: etiquetas HTML incorrectas

Uno de los errores más comunes al comenzar con HTML ocurre cuando nuestras etiquetas de apertura y cierre no coinciden.

Observa este ejemplo.

Abrimos el título utilizando una etiqueta `h1`, pero lo cerramos utilizando una etiqueta `h2`.

Esto es incorrecto.

Si comenzamos con `h1`, también debemos cerrar utilizando `h1`.

Otro error frecuente es olvidar cerrar una etiqueta.

Por ejemplo, podemos comenzar un párrafo utilizando `p`, pero olvidar colocar su etiqueta de cierre.

Aunque el navegador puede intentar interpretar nuestro código, estos errores pueden provocar resultados inesperados.

Por eso, cuando una página se vea diferente a lo que esperábamos, una de las primeras cosas que podemos revisar son nuestras etiquetas HTML.

# 2:55 – 4:05 | Diapositiva 4 — Error común 2: errores en CSS

También podemos cometer errores pequeños al escribir CSS.

Observa esta regla.

Queremos cambiar el color de nuestro título, pero escribimos la propiedad `color` y el valor `royalblue` sin colocar los dos puntos entre ellos.

En CSS, una propiedad y su valor se separan utilizando dos puntos.

La forma correcta sería:

`color`, dos puntos, `royalblue`, punto y coma.

También es recomendable terminar cada declaración utilizando punto y coma.

Pequeños símbolos como los dos puntos, el punto y coma o las llaves son muy importantes en CSS.

Si algo no funciona como esperamos, revisar estos elementos puede ayudarnos a encontrar el problema rápidamente.

# 4:05 – 5:10 | Diapositiva 5 — Selector correcto y código ordenado

Otro error frecuente ocurre cuando utilizamos el selector equivocado.

Imagina que en nuestro HTML tenemos un título creado con `h1`.

Pero en CSS escribimos una regla para `h2`.

En ese caso, nuestro título principal no cambiará porque CSS está buscando un elemento diferente.

Por eso debemos comprobar que el selector que utilizamos realmente corresponda con el elemento que queremos modificar.

También es importante mantener nuestro código ordenado.

Un código organizado es mucho más sencillo de leer.

Y si aparece algún error, también será más fácil encontrarlo y corregirlo.

Nuestro objetivo no debe ser únicamente conseguir que el código funcione.

También debemos intentar que sea fácil de entender.

# 5:10 – 6:30 | Diapositiva 6 — ¿Qué hacer cuando algo no funciona?

Cuando programamos, es completamente normal que algo no funcione a la primera.

En lugar de cambiar muchas cosas al mismo tiempo, podemos seguir un proceso sencillo.

Primero, revisa el último cambio que realizaste.

Muchas veces el problema se encuentra justamente allí.

Segundo, comprueba tus etiquetas HTML.

Revisa que estén correctamente escritas y cerradas.

Tercero, revisa tu CSS.

Comprueba las llaves, los dos puntos y los puntos y coma.

Cuarto, verifica que estés utilizando el selector correcto.

Y finalmente, cambia solamente una cosa a la vez.

Si hacemos muchos cambios al mismo tiempo, puede ser más difícil descubrir cuál de ellos estaba causando el problema.

Aprender a encontrar errores también forma parte de aprender a programar.

# 6:30 – 7:50 | Diapositiva 7 — No necesitas memorizarlo todo

Durante estas lecciones hemos utilizado diferentes etiquetas HTML y propiedades CSS.

Pero hay algo muy importante que debes recordar.

No necesitas memorizarlo todo.

Incluso los desarrolladores con experiencia consultan documentación cuando necesitan recordar cómo funciona una etiqueta o una propiedad.

Una fuente muy útil para continuar aprendiendo es MDN Web Docs.

Allí puedes encontrar documentación, explicaciones y ejemplos sobre HTML, CSS y otras tecnologías utilizadas en desarrollo web.

Lo importante no es memorizar cada etiqueta o cada propiedad.

Lo importante es comprender los conceptos básicos y aprender a buscar la información que necesitas.

Después de este curso también puedes seguir practicando mediante pequeños proyectos.

Puedes crear una página sobre tu videojuego favorito.

Sobre una película.

Sobre un artista.

Sobre un lugar que te guste.

O incluso crear tu propia página personal.

Mientras más proyectos desarrolles, más oportunidades tendrás de practicar.

# 7:50 – 9:20 | Diapositiva 8 — Reto final y cierre

Para terminar este curso, queremos proponerte un último reto.

Toma la página que has construido durante estas lecciones y revísala.

Comprueba que tu HTML esté ordenado.

Revisa que tus etiquetas estén correctamente escritas.

Comprueba también tu CSS.

Puedes personalizar nuevamente los colores.

Probar otra fuente.

Revisar tus enlaces.

Y corregir cualquier error que encuentres.

No tienes que conseguir una página perfecta.

El objetivo es aplicar todo lo que has aprendido.

Durante este curso aprendiste a utilizar HTML para construir contenido y CSS para darle estilo.

También aprendiste que equivocarse y corregir errores es una parte completamente normal del proceso de programación.

Ya tienes las herramientas básicas para seguir creando páginas web por tu cuenta.
