# Lección 01 — ¿Qué es el desarrollo web?

**Duración estimada:** 4 minutos
**Tema:** Fundamentos del desarrollo web (HTML y CSS)
**Herramienta de práctica:** CodePen (plan B: W3Schools Try it)
**Conocimientos previos:** Ninguno. Es la primera lección del curso.

## Objetivos de aprendizaje

Al finalizar esta lección, el estudiante podrá:

- Explicar qué es un sitio web.
- Describir cómo llega una página hasta su pantalla.
- Diferenciar HTML (contenido) de CSS (estilo).
- Recordar la fórmula: sitio web = contenido + estilo.
- Espiar el HTML y el CSS de una página con el navegador.
- Probar su primer cambio en vivo en un editor en línea.

## 0:44 – 1:16 | ¿Qué es un sitio web y cómo llega a tu pantalla?

¿Qué es un sitio web?

Un conjunto de páginas conectadas, guardadas en computadoras especiales llamadas servidores, que tú abres con un navegador, como Chrome o Edge.

¿Cómo llega a tu pantalla?

Tú escribes una dirección, el navegador viaja por internet a pedirla, el servidor envía los archivos, ¡y puf! aparece la página.

Es como un restaurante: tú eres el cliente, el navegador es el mesero y el servidor es la cocina.

## 1:35 – 1:54 | HTML: el contenido

HTML le dice al navegador qué contenido hay: títulos, textos, imágenes, botones.

Mira: esta línea dice, aquí va un título que dice Hola, mundo, y el navegador lo muestra.

```html
<h1>¡Hola, mundo!</h1>
```

Las etiquetas son como los letreros de una mudanza: indican qué es cada cosa.

## 1:54 – 2:10 | CSS: el estilo

CSS se encarga de cómo se ve todo: colores, letras, tamaños y posiciones.

Mira esta página sin CSS: aburrida.

Y aquí, el mismo contenido con CSS: ¡otra personalidad!

El contenido no cambió, solo el estilo.

## 2:10 – 2:25 | La fórmula mágica

La fórmula mágica: sitio web es igual a contenido, o sea HTML, más estilo, o sea CSS.

```text
Sitio web = HTML (contenido) + CSS (estilo)
```

Sin HTML no hay nada que mostrar.

Sin CSS, se vería como una página de mil novecientos noventa y cinco.
